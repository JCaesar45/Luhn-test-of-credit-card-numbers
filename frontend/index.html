README

Why This Exists

Luhn's checksum doesn't prove a card is real. It proves a card number is well-formed — the difference between a typo and a plausible identifier. That distinction saves databases from garbage and fraud teams from noise. This page is a working demonstration: type any number, watch the parity walk, see the mod-10 verdict.
